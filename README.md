# PheobeOS 

PheobeOS is a small **OS-style web interface** I built using HTML, CSS and JavaScript.

## Features

- OS-style desktop interface
- Live date and time
- Video Player
- Multiple videos
- Play videos directly inside the window
- Image Gallery
- Draggable application windows
- Closeable windows
- Custom background and styling
- Vertical videos are kept inside the video window

## Technologies Used

- **HTML** — Structure of the desktop, windows, buttons and media
- **CSS** — Layout, background, styling and window design
- **JavaScript** — Clock, window controls, dragging and video selection

This project helped me understand how different parts of JavaScript interact with HTML. Also I learned how to use canva to make the wallpaper.
